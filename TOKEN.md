# Shipwatch token

**Status: no token has been launched.**

Any token that uses the Shipwatch name, logo or website today was not created by us.

## How a launch will be announced

When a token launches, one commit to this repository will do all of the following at once:

1. Replace this file with the mint address, the creator wallet and the creation transaction.
2. Update `token.toml`, which the site's [verify page](https://shipwatch.bwltd.kr/verify.html#token) reads.
3. Add the launch post under [`posts/`](posts/), which is then published on X.

An address that appears anywhere else first is not ours. Check the full address, not only its first and last characters.

## What this file will state

- The mint address and the launchpad it was created on.
- The creator wallet, the creation transaction, and a message signed by that wallet naming this repository.
- How many tokens the team bought at creation, and the policy for selling them.
- Where creator fees go.
- The exact metadata file and image, also committed here.

## What we will not do

- Launch from, or buy with, wallets that are not disclosed here.
- Bundle purchases across several wallets at creation.
- Promise a price or a return. Shipwatch is a tool. A token attached to it is not an investment contract and may lose all of its value.
