      READ THE EVIDENCE

      An edit is a reason
      to look closer.

      Shipwatch compares a linked homepage and up to three scripts or stylesheets hosted on the same website. Each event shows the previous check, the new observation, and the evidence available. The first GitHub repository linked in page HTML is also checked for public releases, including prereleases, hourly.

      A code change can be a redesign, a fix, or a routine build. Successful requests establish availability to our observer. A blocked request appears with its error. Price feeds, contracts, treasury backing, and released features require their own checks.

      The first check establishes a baseline. Later differences enter the edits feed. A change that keeps recurring on one website, such as rotating text or alternating builds, is listed once as its latest occurrence and marked as recurring. During this pilot, the shared watchlist supports 40 projects. A token’s linked site comes from its DEX Screener listing. Repository links express that website’s association.
